### 📥 Установка приложения

1. Нажмите на зелёную кнопку **[Скачать APK (Android)](https://github.com/Cloxoff/iME-Weather/releases/latest)** выше.
2. В блоке **Assets** скачайте файл `app-release.apk`.
3. Откройте загруженный файл на смартфоне и подтвердите установку.

---

### ✨ Ключевые особенности

* ⚡ **Точный прогноз:** Данные об актуальной температуре, влажности, давлении и скорости ветра.
* 📅 **Детализация:** Почасовой прогноз на текущие сутки и подробная сводка на 7 дней вперед.
* 📍 **География Туркменистана:** Полный список городов и этрапов всех 5 велаятов + Ашхабад.
* 🌐 **Мультиязычность:** Встроенный интерфейс на 3 языках (**Türkmençe**, **Русский**, **English**).
* 💾 **Офлайн-режим:** Кэширование последних полученных данных для работы без стабильного интернета.
